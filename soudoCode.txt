=====================================================
سودوکد اصلاح‌شده مرحله ۱: مدل دیتابیس متمرکز بر شماره موبایل
=====================================================
۱. بررسی و ویرایش مدل User در Prisma:
   - id: شناسه یکتای کاربر
   - name: نام و نام خانوادگی کاربر (ثبت در هنگام نام‌نویسی)
   - phone: شماره موبایل کاربر (ضروری و Unique جهت لاگین و OTP)
   - phoneVerified: وضعیت اعتبارسنجی شماره (Boolean، پیش‌فرض false)
   - email: ایمیل کاربر (اختیاری جهت تکمیل پروفایل در آینده)
   - emailVerified: وضعیت تایید ایمیل (Boolean)
   - role: نقش کاربر (پیش‌فرض user، برای دسترسی ادمین admin)
   - image: تصویر آواتار پروفایل (اختیاری)
   - زمان‌بندی: createdAt و updatedAt

۲. نگه‌داشتن مدل‌های زیرساختی Better Auth:
   - مدل Session: برای سشن‌های لاگین موفق کاربر
   - مدل Account: برای ذخیره رمز عبور (در صورت استفاده از لاگین با پسورد)
   - مدل Verification: برای ذخیره کدهای موقت ۶ رقمی OTP با زمان انقضا (برای ورود پیامکی و ریست پسورد)

۳. اجرای دستور prisma db push برای اعمال در Supabase PostgreSQL
۴. اجرای prisma generate برای به‌روزرسانی تایپ‌های کلاینت


=====================================================
سودوکد مرحله ۲: راه‌اندازی هسته Better Auth و API Route
=====================================================
۱. بررسی و اضافه کردن کلید امنیتی:
